# DoubleVerify

> DoubleVerify (NYSE: DV) is a digital media measurement, data and analytics platform. Its
> Media AdVantage Platform (DV MAP) verifies ad impressions across the open web, social,
> connected TV and commerce media — detecting fraud and invalid traffic, measuring
> viewability and attention, scoring brand suitability and contextual relevance, and
> attributing outcomes. DoubleVerify is MRC-accredited.

## What an agent can actually reach

DoubleVerify has two machine-callable surfaces. Both require a DV Pinnacle account; neither
is self-service, and DoubleVerify publishes no OpenAPI for either.

- DV Neura MCP Server — https://mcp.doubleverify.com/mcp — a live remote Model Context
  Protocol endpoint. An unauthenticated `tools/list` returns HTTP 401 with an OAuth
  challenge, so the tool manifest is not public. DoubleVerify states that clients can
  connect the DV Neura Insight Agent from Anthropic Claude today, with Google Gemini and
  Microsoft Copilot to follow.
- DV Report Data API — https://data-reporting.doubleverify.com — an asynchronous reporting
  API. Known paths: /requests, /requestTypes, /compatibility, /dataloadtime. Data is
  retrieved as a CSV stream (`Accept: text/csv`); a request ID stays valid for 30 days.
  Tokens are minted by the user in DV Pinnacle under Analytics → Data API.

## Authentication

- MCP: OAuth 2.1 bearer token from https://dv-ciam.doubleverify.com/realms/pinnacle
  (Keycloak), scopes `openid email profile`. Protected-resource metadata (RFC 9728) is
  served at https://mcp.doubleverify.com/.well-known/oauth-protected-resource/mcp
- Report Data API: bearer token generated in DV Pinnacle. Contact dataapi@doubleverify.com
